# Introdução ao Projeto

## Visão Geral
Este projeto foi desenvolvido para a disciplina de **Compiladores 1** da Universidade de Brasília (UnB), com o objetivo de construir um compilador funcional para uma linguagem inspirada em C. A linguagem gerada traduz diretamente para **assembly NASM**, utilizando macros semânticas para simular abstrações de alto nível.

## Objetivo
Desenvolver um compilador funcional que processe uma linguagem customizada, compilando-a para assembly NASM com o suporte a estruturas, controle de fluxo, funções e variáveis com escopo.

## Metodologia
O projeto utilizou a metodologia **Scrum**, com um ciclo de desenvolvimento iterativo baseado em **sprints de 14 dias**. As principais cerimônias e artefatos utilizados foram:
- Backlog priorizado com Épicos, Features, User Stories e Tasks;
- Reuniões de planejamento e acompanhamento;
- Sprint Reviews e Retrospectivas internas;
- Registro de atualizações em grupo via WhatsApp e GitHub.
